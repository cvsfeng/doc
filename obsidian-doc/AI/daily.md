# 🚀 零基础到大模型全栈开发：24周自学打卡表

**学习节奏：** 每周建议投入 10-15 小时（按每天 2 小时或周末集中攻克）。

## 🧱 第一阶段：AI 共同基石（第1-6周）

**目标：掌握与机器沟通的语言和数据处理能力。**

- [ ] **第 1 周：Python 核心语法通关**
    
    - [ ] Day1: 安装 Anaconda 与 VS Code，跑通 `print("Hello AI")`
        
    - [ ] Day2: 掌握变量与基础数据类型（整数、浮点数、字符串、布尔值）
        
    - [ ] Day3: 掌握核心数据结构（列表 List、字典 Dictionary）
        
    - [ ] Day4: 掌握逻辑控制（If / Else）
        
    - [ ] Day5: 掌握循环结构（For / While 循环）
        
    - [ ] Day6: 掌握函数的定义与调用（`def`, `return`）
        
    - [ ] Day7: 编写一个简单的终端小游戏（如猜数字）巩固语法
        
- [ ] **第 2 周：Python 进阶与面向对象**
    
    - [ ] 学习类与对象（Class & Object）的基础概念
        
    - [ ] 掌握错误与异常处理（`try / except`）
        
    - [ ] 学会使用 Python 读取和写入本地的 TXT 文件
        
- [ ] **第 3 周：API 与网络请求基础**
    
    - [ ] 学习 `requests` 库，搞懂什么是 GET 和 POST 请求
        
    - [ ] 能够用 Python 从网络上抓取一段简单的 JSON 数据并解析
        
- [ ] **第 4 周：AI 数学概念扫盲**
    
    - [ ] 线性代数：理解矩阵乘法的物理意义（不需要手算，懂概念即可）
        
    - [ ] 概率论基础：理解概率分布、贝叶斯定理的基本逻辑
        
    - [ ] 微积分概念：理解“导数”与“梯度下降”（AI如何寻找最优解的直觉）
        
- [ ] **第 5 周：科学计算 NumPy**
    
    - [ ] 安装并导入 `numpy`，理解多维数组（N-dimensional array）
        
    - [ ] 学习 NumPy 的基础矩阵运算操作
        
- [ ] **第 6 周：数据处理利器 Pandas**
    
    - [ ] 学习 `pandas` 中的 Series 和 DataFrame 概念
        
    - [ ] 能够用 Pandas 读取 Excel/CSV 表格，并进行简单的数据清洗和筛选

## 🟡 第三阶段：核心应用开发 - RAG与网页端（第10-13周）

**目标：打造属于你的本地私有知识库助手，并做成网页。**

    - [ ] 学习用代码读取 PDF 和 Word 文档
        
    - [ ] 学习文本切分技术（Chunking），搞懂重叠度（Overlap）的意义
        
    - [ ] 调用 Embedding 模型，将文本转换为多维向量数据
        
- [ ] **第 11 周：向量数据库实战 (Vector DB)**
    
    - [ ] 安装并运行轻量级向量数据库 `ChromaDB` 或 `FAISS`
        
    - [ ] 实现文档向量的存入（Insert）与相似度检索（Search）
        
- [ ] **第 12 周：LangChain 框架整合核心**
    
    - [ ] 了解 LangChain 的基本架构（Models, Prompts, Output Parsers）
        
    - [ ] 使用 LangChain 将“搜索文档”和“大模型回答”串联起来，完成基础 RAG
        
    - [ ] 加入 `Memory` 模块，让你的 RAG 机器人拥有记忆
        
- [ ] **第 13 周：AI 应用前端可视化 (UI)**
    
    - [ ] 学习 `Streamlit`（或 `Gradio`）基础语法
        
    - [ ] 将第 12 周的代码打包，做成一个可以通过浏览器访问的“知识库问答网页 APP”
